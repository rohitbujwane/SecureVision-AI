Supported Schema

The analyzer supports network flow data with the following features. Column names are automatically normalized.

Flow Metrics

  • flow_duration
  • flow_bytes_per_s
  • flow_packets_per_s
  • flow_iat_mean

Packet Features

  • total_fwd_packets
  • total_bwd_packets
  • fwd_packet_length_mean
  • bwd_packet_length_mean

TCP Flags

  • syn_flag_count
  • ack_flag_count
  • psh_flag_count
  • rst_flag_count

Optional

  • timestamp
  • source_ip
  • dest_ip
  • label (ground truth)

Minimum 3 numeric features required. See data/README.md for details.
